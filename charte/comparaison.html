Charte de l'amphi

Trois palettes et six polices pour le tableau, appliquées à un écran de Reel avec la taupe. Choisis une palette et une police, puis réponds dans le terminal.

Univers : la feuille à carreaux

La feuille occupe tout l'écran, sans mur ni tableau, avec la palette Feutres et Handlee. Deux quadrillages possibles.

Police du code

JetBrains Mono, déjà utilisée dans la première version : elle distingue 0 et O, 1, l et I, ce qui compte sur un écran de téléphone.

lock() if (stock > 0) { stock = stock - 1 } unlock() 0O 1lI
Les maquettes reprennent les proportions d'un écran 1080×1920. Le sélecteur de police au-dessus des palettes change la police dans les trois maquettes.
